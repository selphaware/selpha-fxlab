## The battery (primary 2015-01-01 → 2025-02-28; full history where stated)

Costs everywhere from `fxlab.costs.IBCostModel` at the pre-registered ladder
1.0 / 1.2 / 1.5 / 2.0× — never a hand-typed pip figure. Spread from stored
ticks by hour; commission per pre-reg (0.20 bp, USD 2 minimum) — NOTE P0-A
is not yet implemented, so for non-USD-quoted pairs report commission in
quote currency AND state the caveat on every table; no result here is a
scorecard, so the COST_FIX gate rule is not triggered, but the gap is named.

1. **Round-trip cost floor by pair × session × vol tercile**: median and p90
   spread (R3: within tick-count bands) plus commission, at each ladder rung;
   the cheapest executable band per pair (D3's execution constraint,
   quantified); minimum viable notional where the USD 2 minimum binds.
2. **Realised-move distributions by pair × horizon** (5m, 30m, 1h, 4h, 1d):
   |return| quantiles vs the cost floor → the share of moves that exceed
   round-trip cost at each rung. This is the "where can edge even exist"
   map: a horizon where the median move is below cost cannot host a
   strategy that trades every bar.
3. **Minimum viable holding period per pair**: the shortest horizon at which
   realised move p50 clears cost at 1.5×, by session and regime.
4. **Formal test of the D2 test set**: for each of the 11 cells, the implied
   gross edge per trade of a lag-1 reversion rule (|ρ(1)| × sd, plus the
   variance-ratio implied multi-lag version) vs round-trip cost at every
   rung, unconditionally and restricted to the cheapest session band and to
   each vol tercile. Verdict per cell: SURVIVES (clears 1.5×) / PARKED
   (clears 1.2× not 1.5×, per pre-reg #1) / CLOSED. State the arithmetic.
   This is an analytical bound, not a backtest — a cell that fails here
   cannot pass a backtest, which is the point; a cell that passes gets its
   backtest in T7.
5. **Roll-window regime quantified for the record** (pre-reg #4): cost vs
   move inside the derived 16:00–18:00 NY window per pair.
6. **Era question (R7 evidence)**: on 1h/1d bars across the full history
   (AUDUSD 2011+), the cost floor and move-vs-cost map by era (2005–08,
   2009–12, 2013+), spreads under R3's density control, and the by-year
   cross-check agreement table beside it. Deliver an EVIDENCE table for the
   checkpoint's pre-2013 decision (training data / stress test only /
   excluded) — recommend, do not decide.
7. **Cost sensitivity summary**: for each pair, how the executable universe
   (horizons × sessions) shrinks from 1.0× to 2.0× — the shape of what a
   cost-model error would cost us.
